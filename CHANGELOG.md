# Changelog

## 1.0.0 - First release

- Automatic layered decoding for the Linux terminal, with readable step traces.
- Offline Python runtime with no third-party runtime dependencies.
- Encodings, bounded decompression and classical cipher recovery.
- English and CTF flag scoring with a bundled language model.
- Byte-preserving input/output, reports and author watermark.
- Source installer, Python package metadata and GitHub setup instructions.
- Expanded evaluation with 17,040 cases and all measured failures retained.
- Regression coverage for format boundaries, corrupted streams and CLI behavior.
