# Offline English model provenance

`english.json.gz` contains word and letter-quadgram **counts**, not full books.
It was generated by `scripts/train_language.py` from the bodies of:

- Lewis Carroll, *Alice's Adventures in Wonderland* (1865):
  https://www.gutenberg.org/ebooks/11
- Jane Austen, *Pride and Prejudice* (1813):
  https://www.gutenberg.org/ebooks/1342

These literary works are in the public domain in the United States. Book metadata
and the distribution header/footer were excluded before counting. A small list
of common technical terms is added in the training script. No benchmark sentences
or expected flags are inserted into the model.

The evaluation uses separate authored examples and held-out prose from Arthur
Conan Doyle's *The Adventures of Sherlock Holmes* (1892), Gutenberg #1661:
https://www.gutenberg.org/ebooks/1661

Reference implementation ideas, with no source code copied:

- Nested format detection: https://github.com/gchq/CyberChef/wiki/Automatic-detection-of-encoded-data-using-CyberChef-Magic
- Single-byte XOR candidate scoring: https://cryptopals.com/sets/1/challenges/3
- Hamming-distance key-size estimation: https://cryptopals.com/sets/1/challenges/6
- Base encoding definitions and known-answer vectors: https://www.rfc-editor.org/rfc/rfc4648


The evaluation-only excerpts in `benchmarks/prose.txt.gz` come from the same
#1661 snapshot. They are fixture inputs, never language-model training inputs.
